# Code of Conduct

Aria adopts the [Contributor Covenant v2.1] as its code of
conduct. The full text is incorporated by reference; the
highlights below are the parts that come up most often in
practice.

[Contributor Covenant v2.1]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## In short

- Be respectful. Disagree with code, not people.
- Assume good intent when reading a comment or PR review. Most
  curt-sounding feedback is someone trying to be efficient,
  not hostile.
- Keep discussion technical. Aria is a Swift library; that's
  the conversation. Political / religious / ideological side-
  arguments don't belong on issues, PRs, or discussions.
- No harassment. No personal attacks. No discrimination on the
  basis of any protected characteristic.

## Scope

This code applies everywhere Aria's community interacts:

- GitHub issues, pull requests, discussions, and code reviews.
- Any chat / forum / video call where you're representing the
  Aria project.
- Off-platform interactions when they affect a contributor's
  ability to participate here (e.g. brigading from elsewhere).

## Reporting

If you experience or witness behaviour that violates this code,
email **conduct@prasadpamidi.dev**. Reports are confidential.
We'll respond within **5 business days**.

Reports that name a maintainer are reviewed by an uninvolved
co-maintainer (or, while Aria is a single-maintainer project, by
an outside reviewer of your choice).

## Enforcement

The maintainer team enforces this code through the [Contributor
Covenant enforcement guidelines]: a documented escalation from
private clarification to temporary suspension to permanent ban,
depending on severity and pattern. We don't ban first-time good-
faith mistakes; we do ban patterns of harassment or any
deliberate harm.

[Contributor Covenant enforcement guidelines]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines
